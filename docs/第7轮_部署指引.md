# 第 7 轮部署指引：计算棒黑匣子 + 地面端（大白话版）

日期：2026-09-30　适用：`docs/第7轮_计划_空中端黑匣子与计算棒部署.md` 第六、七节

一句话：**计算棒 = 黑匣子（插电就干活，永远不用碰）；地面端电脑 = 遥控器（所有按钮都在这）。**

---

## 一、两个便携包（现场两端必须配套）

| 包 | 拷到哪 | 入口程序 | 作用 |
|---|---|---|---|
| `dist/空中端黑匣子便携包/` | 计算棒 | `uav_gpr_air_service.py`（pythonw 无窗口后台） | 采数据、发数据、断线补传、磁盘自动清理 |
| `dist/地面站便携包/` | 地面端电脑 | `run_ground_station.bat` | 地面站软件 + 「空中端设备」遥控面板 |

> 两个包都是"整个文件夹拷走就能用"（自带 Python 运行时和全部依赖），不用安装任何东西。
> 两端版本必须配套（地面端面板显示的程序版本要和棒子上 `logs\air_service.log` 启动行一致）。

---

## 二、计算棒一次性安装（5 步，只需接一次屏幕键盘）

1. **拷包**：把 `空中端黑匣子便携包` 整个文件夹拷到计算棒（U 盘或网线直连拷贝都行），放哪都行（例如 `D:\air_blackbox\`）。
2. **装自启**：进入文件夹，右键 `安装到计算棒.bat` → **以管理员身份运行**（UAC 弹窗点"是"）。它会自动：
   - 注册计划任务 `UAVGPR_AirBlackBox`：**开机启动（延迟 30 秒）+ 用户登录** 双触发；**程序崩溃 60 秒自动拉起**；**无执行时限**；当前用户身份运行；
   - 立即启动一次服务；
   - 检查棒子 IP、检查 LibreVNA 驱动（见下两步）。
3. **查静态 IP**：看脚本 `[2/4]` 的输出，确认有线网卡 IP 是 **192.168.144.21**。不是就按提示改：`设置 → 网络和 Internet → 以太网 → IP 分配 → 手动`，填 `192.168.144.21` / 掩码 `255.255.255.0`。
4. **插 LibreVNA**：USB 插上雷达，看脚本 `[3/4]` 的输出显示 `[OK] LibreVNA USB device present`；若显示未检测到，先装驱动（设备管理器出现未知设备时手动装 WinUSB），重新插拔后再跑一次安装脚本即可。
5. **拔屏收工**：拔掉屏幕键盘，棒子只留 **电源 + 网线**（网线接 HM30 空中端网口）。

> 以后棒子通电就全自动：开机 30 秒后服务自启 → 自动连地面端（连不上每 5 秒起退避重试，最长 30 秒一次，永不放弃）→ 等地面端下命令。

## 三、日常使用（全在地面端）

1. 地面端电脑双击 `run_ground_station.bat`。
2. 菜单打开 **「空中端设备」面板**：看到"连接状态：已连接"、雷达 USB、run_id、积压、磁盘剩余、程序版本。
3. 点面板 **「测试雷达」**：显示固件/协议号即雷达在线。
4. 主界面点 **「开始」** 采集：B-scan 出图，数据落地面端 `runs/`，同时棒子本地也存一份。
5. 改 GNSS 串口、切引擎、切模拟器：都在面板上点，空中端自动回写配置并回执确认。
6. 拔地面端网线也不怕：棒子照常采集+本地保存，网线插回后自动补传，面板积压归零。

## 五、常见问题排查

**Q1 面板一直"重连中"连不上？**
① 地面端软件是否开着（先开地面端，棒子会自己找过来）；② 棒子 IP 是否 `192.168.144.21`（重跑安装脚本看 `[2/4]`）；③ 网线是否接 HM30 空中端网口、地面端防火墙是否放行 8765 端口；④ 还不行 → 拷出棒子 `logs\air_service.log` 最后 100 行，看"Remote send retrying"后面的原因。

**Q2 "测试雷达"失败？**
USB 没插好 / 驱动没装好（设备管理器应有 LibreVNA，`VID_1209&PID_4121`）。面板切到"模拟器"再测试会显示"模拟器模式"，这是**正常的**（模拟器没有真雷达）。

**Q3 采集没数据？**
面板看"是否采集：采集中"再说；雷达 USB 掉线时地面端 stop 后重新 start 即可（常驻服务会自动恢复会话）。

**Q4 磁盘清理告警（DISK-ALARM）？**
棒子磁盘剩余低于 20GB 才触发，从最老的 run 删起清回 40GB；日志逐条记账。出现"未送达数据被清理"告警说明满到必须丢弃未上传数据——尽快备份/扩容 `gpr_runs`。

**Q5 想停掉棒子程序 / 升级？**
见包内 `使用说明（黑匣子必读）.txt` 第六节：`关闭自启.bat` 停服务并取消自启；`升级_替换程序.bat` 一键升级（旧文件夹自动备份，配置/日志/数据全保留）。

**Q6 升级后地面端面板版本没变？**
面板显示的是棒子当前运行版本；确认升级脚本 `[4/5]` 已重启任务，或重跑 `安装到计算棒.bat` 后再看。
